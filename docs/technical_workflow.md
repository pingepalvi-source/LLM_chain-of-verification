# Technical Workflow: Chain-of-Verification (CoVe)

## 1. Introduction

Chain-of-Verification (CoVe) is a prompting technique designed to improve the factual reliability of responses generated by Large Language Models (LLMs).

Instead of relying entirely on a single generated response, the system introduces intermediate verification steps before producing its final answer.

This project implements a CoVe workflow using Python and Google's Gemini API.

## 2. System Architecture

The system consists of four primary stages:

1. Initial Draft Generation
2. Verification Question Generation
3. Verification Question Answering
4. Final Answer Generation

### Workflow

```text
             User Question
                   |
                   v
          Initial Draft Answer
                   |
                   v
       Generate Verification Questions
                   |
                   v
        Answer Verification Questions
                   |
                   v
          Generate Final Answer
                   |
                   v
            Verified Response
```

## 3. Detailed Workflow

### Stage 1: Initial Draft Generation

The user's question is passed to the Gemini model through the `get_draft_answer()` function.

The model generates an initial response, which serves as the basis for subsequent verification steps.

### Stage 2: Verification Question Generation

The `generate_verification_questions()` function uses the original question and draft response to generate questions that examine important factual claims.

The purpose is to identify information that may require further checking.

### Stage 3: Verification Question Answering

The `answer_verification_questions()` function obtains answers to the generated verification questions using the Gemini API.

These answers provide additional information that can be considered during final response generation.

### Stage 4: Final Answer Generation

The `generate_final_answer()` function receives:

- Original user question
- Initial draft answer
- Generated verification questions
- Answers to verification questions

Using this information, the model produces a final response intended to address potential inconsistencies in the initial draft.
